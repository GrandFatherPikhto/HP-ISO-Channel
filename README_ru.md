# HP-ISO-Channel v0.99 — файлы для производства

Плата развязки. Стоит между контроллером HiPIMS и платами драйверов затворов (HP-Power / HP-Channel).
Сделано в KiCad 10.0.8 из `HP-ISO-Channel-v099.kicad_pcb`.

## Плата

| Параметр | Значение |
|---|---|
| Слои | 2 |
| Размер | 65.92 × 82.78 мм, прямоугольник |
| Толщина | 1.6 мм, FR4 |
| Медь | 35 мкм (1 oz), обе стороны |
| Мин. дорожка / зазор | 0.2 / 0.2 мм |
| Мин. отверстие | 0.3 мм (переходные) |
| Переходные (площадка / сверло) | 55 × 0.6 / 0.3, 16 × 0.8 / 0.4, 4 × 1.0 / 0.5 мм |
| Металлизированные | выводы 0.7–1.0 мм; 2 × 3.5 мм (крепёж H3, H4) |
| Неметаллизированные | 2 × 3.5 мм (крепёж H1, H2) — отдельный файл |
| Пазы / овальные отверстия | нет |
| Компоненты | только сверху |
| Контроль импеданса | не нужен |
| Покрытие, цвета | в проекте не заданы — выбрать при заказе |
